# 独立账号与诊断模块

入口：我的 → 右上角齿轮 → 设置 → 账号与同步。原有全部六个底部导航保留。

账号架构：
- OfficialSignInActivity：独立 account_login 进程，用户在官方站点完成登录和验证，本站不处理密码或验证码；
- OfficialWebsiteGateway：只验证官网会话，不把它冒充红果 App 业务账号；
- AccountRepository：会话代次保护、恢复、退出；
- AccountStore：Android Keystore AES-GCM + AtomicFile，位于 noBackupFilesDir；
- CloudAccountPort：后续账号历史、收藏、点赞与进度写入的契约，**当前没有实际实现**；
- SDK 和播放器仍匿名运行，和账号凭据完全分开。

设计原则：独立编写账号代码，没有复制其他 GPL 项目的源码。

应用设置：恢复上次播放、自动画中画两个可实际控制的开关。

诊断：设置页面通过系统创建文件窗口导出 TXT。默认包含设备与应用版本、当前导航、播放状态、收藏与历史数量、约 500 个内存事件和滚动持久事件；崩溃堆栈保留异常类与方法行号，不留异常 message。可选导出本应用进程 Logcat，该选项每次使用后关闭。会尽量遮蔽 Cookie、Token、长数字和 URL，但无法保证所有第三方日志无隐私，请分享前检查。

不自动上传数据与日志；清空诊断不清空收藏、历史、账号。

验证边界：官网登录与身份恢复需真机验收；红果 App Passport 手机号认证、云端数据签名、云同步和个性化推荐仍未接入，因此不将官网登录标识成“云账号已同步”。
